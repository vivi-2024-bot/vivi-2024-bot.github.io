プライバシーポリシー

対象：「YouTube分析ツール（読み取りのみ）」（以下「本アプリ」）

1. 本アプリが利用する情報

本アプリは、Googleアカウントで許可された次の2つの読み取り専用の権限だけを使い、運営者自身のYouTubeチャンネルの情報を読み取ります。

  • YouTube の読み取り（youtube.readonly）：チャンネル名、動画のタイトル・チャンネル名
  • YouTube アナリティクスの読み取り（yt-analytics.readonly）：視聴回数、流入元、視聴者の年齢と性別の割合（個人を特定しない集計値）

2. 利用目的

運営者が自分のチャンネルの視聴状況を確認し、動画の企画に役立てるためだけに利用します。

3. 保存と共有

  • 取得したデータは、運営者のパソコンの中にだけ保存します。
  • Googleの認証情報は、運営者のパソコンのmacOSキーチェーンに保存し、外部に送りません。
  • 取得したデータや認証情報を、第三者に販売・提供・共有しません。広告にも利用しません。

4. 利用者

本アプリは運営者本人のみが使用する個人用ツールであり、一般の方には提供していません。

5. アクセスの取り消し

本アプリへのアクセスは、Googleアカウントの「サードパーティ製のアプリとサービス」の設定（https://myaccount.google.com/connections）からいつでも取り消せます。

6. Google API サービスのユーザーデータに関するポリシー

本アプリによるGoogle APIから受け取った情報の使用は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。
